# Examples

Input files used by the examples in the [README](../../README.md) and the
[CLI guide](../cli_usage.md). Run the commands from this directory, e.g.

```bash
$ hashmol3d water.xyz
hm3d_v12_p4_H2O_q0m1_8e9eedf5032cf387541d637f56c682dc
```

- `water.xyz`: water, the identifier shown throughout the docs.
- `benzene.xyz`: benzene.
- `ethanol.xyz`: ethanol.
